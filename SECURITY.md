# Security policy

av1forGPU is experimental research software: it parses raw YUV input and writes AV1 streams, and it is not hardened for
untrusted input. Please report crashes or memory-safety problems found with malformed input through a
[GitHub security advisory](https://github.com/7drien/av1forGPU/security/advisories/new) rather than a public issue.
Include the command line, input dimensions and, if possible, a minimal input.
